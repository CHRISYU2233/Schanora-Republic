## 当前产品行为

安装一个 `@schanora/client` 插件后，本机 DSH 加载面板，Host 自动启动或复用同目录的本地内核。已安装插件只使用本地模式。开发预览保留模拟与既有 Gateway 调试入口。模型使用本机服务，未配模型时提供 BM25 及可引用摘录。索引本地重建，数据为 Markdown 和 JSON。

要使用 OneDrive，可将 `SCHANORA_ROOT` 或插件 `root` 指到已经同步到本机的共享目录。共享库采用单写机器，其余用户在同步完成后刷新。当前会话与库共用数据根，选择共享整个数据根也会同步会话文件。
